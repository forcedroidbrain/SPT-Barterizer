# SPT Barterizer 0.2.0

Adds an optional setting for more variety among similarly priced barter payments.

- New `recipeValueTolerancePercent` setting, range `0` to `100`.
- Default `0` preserves the recipes generated by previous versions, including when the setting is absent from an existing config.
- Set it to e.g. `25` to randomly select among completions whose total handbook value is up to 25% above the cheapest valid completion of the current recipe. This can increase the price paid for variety; it is not a 25% cap above the original cash price.
- Recipes remain deterministic for the same seed, configuration, offer IDs and payment pool.
- Existing barters, stock, purchase limits, quest mappings and HardcoreRules exemptions remain unchanged. Loose ammunition remains excluded by default.

## Installation and upgrade

For SPT 4.1.6. Extract `SPT-Barterizer-0.2.0.zip` into the SPT root while the server is stopped. On upgrade, back up your existing mod folder and preserve your current `config.json`. Add `"recipeValueTolerancePercent": 25` to that JSON object if you want to enable variety. Restart the server after configuration changes.

OpenBarters and HardcoreRules are optional and are not included in this package. See README.md for configuration, attribution, AI assistance disclosure and support details.
